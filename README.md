# Better-ls
A better version of the classic "ls" command written in rust. It is elegent and fast.

## Contribution

``` bash
git clone https://github.com/RayAntariksha/better-ls.git
```
This is a very simple project, so I would highly recommend beginners to take a look at the source code, make it a little bit better and contribute to it.
Everyone is free to raise issues, send pull request or make any other kind of contribution. You don't need to hesitate to send pull request even if it makes the project worse. We can always fix it later :)

## Installation

### Prerequisites:
- Rust to be installed
- A nerd font to be installed and enabled in the terminal
- Git installed

Sadly no packages are available right now so you'll have to compile it yourself with the following command :
``` bash
git clone https://github.com/RayAntariksha/better-ls.git
cargo install --path ./better-ls
```
> [!WARNING]
> I do not recommend anyone to use this seriously right now as it is under development. The only person who is stupid enough to use this is probably me.
